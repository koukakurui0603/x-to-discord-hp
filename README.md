# Xポスト → Discord転送ボタン (x-to-discord-hp)

X（旧Twitter）のタイムラインやプロフィール画面上にある**各ポストの下部（いいね・共有の並び）に、自分だけに見える `📌` ボタンを追加**するスクリプトです。

ボタンを1クリックするだけで、そのポストのURLを自分のDiscordチャンネル（Webhook）へ送信できます。個人サイト側のPHPプログラムと組み合わせることで、「自分で選んだXポストだけを個人サイトのTWEET欄に表示する」運用に使えます。

> **【制作・コードについて】**  
> 本スクリプトは、非エンジニアである制作者（高殻るい）が企画・設計・検証を行い、コーディングは生成AI（Google Gemini）との協働により作成しています。

## 1. Google Chrome への導入手順

1. Chromeウェブストアから拡張機能 **「Tampermonkey（タンパーモンキー）」** をインストールします。
2. **【重要】Chromeの許可設定を行う（これをしないと動きません）**
   * Chromeのアドレス欄に `chrome://extensions/` と入力してEnterキーを押します。
   * 画面右上にある **「デベロッパー モード」** のスイッチを **ON** にします。
   * Tampermonkeyの欄にある **「詳細」** を押し、下に **「ユーザースクリプトを許可」** という項目があればこちらも **ON** にします。
3. 本スクリプトをインストールします。
   * GitHubから導入する場合： `x_to_discord_hp.user.js` の **「Raw」** ボタンを押すと、Tampermonkeyのインストール画面が開きますので「インストール」を押します。
   * 手動で入れる場合：Tampermonkeyアイコン →「新規スクリプトを追加」を開き、中身を消してコードを丸ごと貼り付け、`Ctrl + S` で保存します。

---

## 2. 初期設定と使い方

1. Google Chrome で X（ `https://x.com/` ）を開きます（すでに開いていた場合は `F5` キーで再読み込みしてください）。
2. 各ポストの右下（共有ボタンの隣）に **`📌`** ボタンが表示されます。
3. 最初にどれか1つ **`📌`** をクリックする（またはブラウザ右上のTampermonkeyアイコン →「⚙️ HP転送先Webhook設定を開く」をクリック）と、設定画面が開きます。
4. 中継用に作ったDiscordチャンネルの **Webhook URL**（およびお好みのボタン絵文字）を入力し、「🔍 接続確認」→「💾 保存する」を押します。
5. あとは自分のHPに載せたいポストの **`📌`** を1回クリックするだけ！`⏳` → `✅` になればDiscordへ送信完了です。
