# Xポスト欄・半自動再現システム (x-to-discord-hp)

**「公式の埋め込みタイムラインが使えなくなったけれど、自分の個人サイトにX（旧Twitter）のポストを綺麗に並べたい！」**  
そんな個人サイト運営者のための、**1クリック手動ピックアップ型のXタイムライン再現キット**です。

> **【制作・コードについて】**  
> 本システムのコードは、非エンジニアである制作者（高殻るい）が企画・設計・実機検証を行い、コーディングは生成AI（Google Gemini）との協働により作成しています。中身をご確認のうえ自己責任にてご利用ください。

---

## このシステムでできること

* **Xを見ながら1クリックでHPへ転送**  
  Google Chrome上で見ている自分のポスト（または紹介したい他人のポスト）の下に出る専用ボタン（`📌`）を押すだけで、そのポストのURLが中継用Discordチャンネルへ送信されます。
* **個人サイト側に最新50件を自動展開**  
  サイト側のPHPプログラムが中継Discordチャンネルから最新50件を読み取り、Xのポスト内容（本文・アイコン・日時・添付画像・動画サムネイル・引用リツイート）を自動取得して、本家X風のスクロールボックスに表示します。
* **リポスト（RT）のヘッダー表示にも対応**  
  リポストした投稿を送った場合は、本家Xのように上部に `🔁 〇〇がリポストしました` と自動で表示されます。
* **サイト専用のひとことメモにも使える**  
  中継Discordチャンネルに直接文字を書き込めば、Xに投稿していない「サイトだけの近況メモ」もタイムラインに混ぜて表示できます。

## 必要なもの

1. **Google Chrome**（パソコン版：送信ボタンを動かすために使います）
2. **Discordアカウント**（非公開の中継チャンネル＆Botを作るために使います）
3. **PHP（7系または8系）が動くレンタルサーバー**（ご自身の個人サイト用）

## 1. Discord側の準備（中継場所とBotを作る）

サイトに載せるポストを一時的に貯めておく「自分だけの非公開チャンネル」と、サイトがそれを読み取るための「Bot」を作ります。

### 1-1. 専用サーバーと中継チャンネルを作る
1. 他の人が誰もいない、**自分専用の非公開サーバー**を作ります（すでにある自分のメモ用サーバーでも構いません）。
2. その中にテキストチャンネルを1つ作ります（例：`#hp-tweet`）。
3. Discordのユーザー設定（歯車マーク）→「詳細設定」→ **「開発者モード」をON** にします。
4. 先ほど作った `#hp-tweet` を右クリック → **「チャンネルIDをコピー」** を押してメモ帳に控えます。

### 1-2. Webhook URLを発行する（Chromeからの送信窓口）
1. `#hp-tweet` チャンネルの歯車アイコン（チャンネルの編集）→ **「連携サービス」** → **「ウェブフック」** → **「新しいウェブフック」** をクリックします。
2. **「ウェブフックURLをコピー」** を押してメモ帳に控えます。

### 1-3. Discord Botを作成する（サイト側の読み込み窓口）
1. **Discord Developer Portal**（ `https://discord.com/developers/applications` ）へアクセスしてログインします。
2. 右上の **「New Application」** から適当な名前でアプリを作成します。
3. 左メニューの **「Bot」** を開きます。
   * **「Reset Token」** を押して表示された長い文字列をコピーし、メモ帳に控えます（※一度しか表示されません。**絶対に他人へ教えないでください**）。
   * **【超重要】** 同じ「Bot」ページを下へスクロールし、「Privileged Gateway Intents」の中にある **`MESSAGE CONTENT INTENT` を必ず ON にし、右下の「Save Changes」を押してください**（※これがOFFだとサイト側が文字を読み取れません）。
4. 左メニューの **「OAuth2」** → **「URL Generator」** を開きます。
   * 「SCOPES」の **`bot`** にチェックを入れます。
   * 下に出る「BOT PERMISSIONS」で **`View Channels`** と **`Read Message History`** にチェックを入れます。
5. 一番下に生成されたURLを開き、1-1で作った自分専用サーバーを選んで「認証（招待）」します。

## 2. Chrome側の準備（送信ボタンの導入）

パソコンの Google Chrome 上で、Xの各ポストの下に専用ボタンを生やします。

### 2-1. Tampermonkeyの導入と許可設定
1. Chromeウェブストアから拡張機能 **「Tampermonkey（タンパーモンキー）」** をインストールします。
2. Chromeのアドレス欄に `chrome://extensions/` と入力してEnterキーを押します。
3. **【重要】** 画面右上にある **「デベロッパー モード」を ON** にします（また、Tampermonkeyの「詳細」を開いて **「ユーザースクリプトを許可」** のスイッチがあればこちらも **ON** にしてください）。

### 2-2. スクリプトをインストールして設定する
1. 以下のリンクをクリックし、Tampermonkeyの画面が開いたら「インストール」を押します。
   * **[▶ x_to_discord_hp.user.js をインストール](https://github.com/koukakurui0603/x-to-discord-hp/raw/main/x_to_discord_hp.user.js)**
2. Google Chrome で X（ `https://x.com/` ）を開きます（すでに開いていた場合は `F5` キーで再読み込みしてください）。
3. 各ポストの下部（共有アイコンのすぐ右隣）に **`📌`** ボタンが表示されます。
4. 最初にどれか1つ **`📌`** をクリックする（またはブラウザ右上のTampermonkeyアイコン →「⚙️ HP転送先Webhook設定を開く」）と設定画面が開きますので、以下を入力して保存します。
   * **Discord Webhook URL（必須）：** 1-2でコピーしたURLを貼り付け（「🔍 接続確認」を押して ✅ が出ればOK）。
   * **ボタンに表示する絵文字：** お好みの絵文字（`📌` や `🦀` など）。
   * **あなたのXのID（任意）：** `@` なしのアカウントIDを入れると、他人の個別ポスト画面から送った時も自動でリポスト扱いになります。
   * **リポスト時の表示名（任意）：** 例 `高殻るい`（空欄でもサイト側の初期名が自動で付きます）。

## 3. 個人サイト（サーバー）側の設置手順

本リポジトリの **`hp_sample`** フォルダの中身を、お使いのレンタルサーバーにアップロードします。

### 3-1. ファイルのダウンロードと設定ファイル作成
1. このGitHubページ右上の緑色の **`<> Code`** → **「Download ZIP」** を押し、ZIPファイルを展開します。
2. 中にある **`hp_sample`** フォルダを開きます。
3. **`tweet_config_sample.php`** をコピーして、同じフォルダ内に **`tweet_config.php`** という名前で保存します。
4. メモ帳などで `tweet_config.php` を開き、1-1と1-3で控えた情報を書き込んで保存します。

~~~php
return [
    'discord_bot_token'   => 'ここにDiscordのBOTトークン',
    'discord_channel_id'  => 'ここに中継用チャンネルのID',
    'cache_ttl_seconds'   => 60,
    'default_author_name'   => 'サイト管理人',
    'default_author_handle' => '@your_account_id',
    'default_avatar_url'    => '',
];
~~~

※`tweet_config.php` は直接ブラウザから開かれても `Access Denied` となって中身が見られない安全設計になっていますが、ご自身でも他の人にファイルを渡さないようご注意ください。

### 3-2. サーバーへアップロードして動作確認
1. `hp_sample` フォルダ内の以下5ファイルを、レンタルサーバーの公開フォルダへアップロードします（`tweet_config_sample.php` は上げなくて構いません）。
   * `sample.html`
   * `x_timeline.css`
   * `x_timeline.js`
   * `api_tweets.php`
   * `tweet_config.php`
2. ブラウザからアップロード先の `sample.html`（例：`https://あなたのサイト/sample.html`）を開いて、動作を確認します。

### 3-3. すでに自分のホームページをお持ちの方（既存サイトへの組み込み方法）
すでに制作済みのページにタイムラインだけを組み込みたい場合は、`sample.html` の代わりに、ご自身のHTMLファイルの好きな場所に以下のタグを貼り付け、同じフォルダに `x_timeline.css`・`x_timeline.js`・`api_tweets.php`・`tweet_config.php` を置くだけで動作します。

~~~html
<!-- <head> 内に貼り付け -->
<link rel="stylesheet" href="x_timeline.css">

<!-- タイムラインを表示したい <body> 内の場所に貼り付け -->
<section class="xtl-wrapper">
    <div class="xtl-header">
        <h2 class="xtl-title">TWEET（最新50件）</h2>
        <button type="button" id="refresh-tweets-btn" class="xtl-refresh-btn">🔄 更新</button>
    </div>
    <div class="xtl-scroll-box" id="tweet-list">
        <div class="xtl-loading">読み込み中です...</div>
    </div>
    <div class="xtl-footer">
        <a href="https://x.com/あなたのID" target="_blank" rel="noopener noreferrer" class="xtl-more-btn">
            続きは X で見る ↗
        </a>
    </div>
</section>

<!-- </body> の直前に貼り付け -->
<script src="x_timeline.js"></script>
~~~

## 4. 使い方・便利な運用方法

* **Xからポストを送る：** Xを見ながら載せたいポストの下にある **`📌`**（または設定した絵文字）を1回押すだけ！ `⏳` → `✅` に変われば送信完了です。
* **サイトへ反映する：** サイト側はアクセス負荷を抑えるため**60秒間のキャッシュ**を持っています。送信直後に確認したい時は、サイト上の **`🔄 更新`** ボタンをクリックしてください（連続連打を防ぐため最低10秒間隔が空きます）。
* **リポスト表示：** リポストされた投稿を送った場合や、他人のポストを送った場合は、サイト上で自動的に上部に `🔁 〇〇がリポストしました` と表示されます。
* **ひとこと近況メモ：** 中継Discordチャンネル（`#hp-tweet`）に直接文字や画像を投稿すると、Xを経由しないサイト限定のつぶやきとしても表示されます。

## 5. 困ったときのQ&A・ライセンス

* **Q. `📌` を押した時にエラー `Blocked by @connect CORS check` が出て送信できません。**  
  **A.** Tampermonkey側の通信許可設定で `discord.com` がブロックされています。Tampermonkeyのダッシュボード → 当スクリプトをクリック → 上部の「設定」タブ →「XHR Security」のホワイトリストに `discord.com` を追加して保存してください。
* **Q. サイト側に「Discordから本文を取得できませんでした」と出ます。**  
  **A.** Discord Developer Portal でBotの **`MESSAGE CONTENT INTENT`** がOFFになっている可能性が高いです。ONにして「Save Changes」を押してから再度お試しください。
* **Q. 手元のパソコンで `sample.html` をダブルクリックしても本物のツイートが出ません。**  
  **A.** PHPプログラム（`api_tweets.php`）はレンタルサーバー上でしか動かない仕組みのため、パソコン上で直接開いた時はデザイン確認用の「プレビュー表示」が出ます。サーバーへアップロードしてからご確認ください。
